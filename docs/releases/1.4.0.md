# Version 1.4.0 - TestFlight candidate

This candidate includes the office composition and technology-readability fixes, responsive notification/control spacing, coordinated furniture finishes, expressive robot faces, obstacle-aware walking and sofa/plant activities. It also includes factory placement/ownership and Undo fixes, save recovery and native-storage race fixes, and shared release gates.

Marketing version: 1.4.0. Initial planned build: 72. The TestFlight workflow sets the archive build number explicitly; FIRST_FREE_BUILD stays at 5 because it is an entitlement boundary.

## Device test handoff

On the exact TestFlight build, record iPhone/iPad model, OS and build:
- Upgrade an existing populated save; verify purchases, finishes, staff and furniture placements, restart and background/resume persistence.
- Exercise fresh and crowded offices in both themes: camera gestures, Shop, Decorate move/rotate/place/reject/cancel/Undo, exit/reload; inspect robot walking, sofa and watering interactions and Reduce Motion.
- Run a connected factory through productive weeks; edit/Undo, save/reload and confirm ownership and cash accounting.
- Exercise subscription purchase, restore, cancellation and legacy entitlement behavior with the existing StoreKit test matrix.
- Sustain office/factory navigation and repeated screen changes; record stutter, artifacts, context loss and thermal behavior.

Software-rendered Windows browser checks are not device performance evidence. Individual use animations for additional chair/sectional types remain outside this candidate. Uploading to TestFlight does not certify App Store readiness or close physical-device, purchase, privacy/account or release-checklist gates.
